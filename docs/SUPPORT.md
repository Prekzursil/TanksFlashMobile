# Support

If you need help with **Tanks**, use one of these channels:

- GitHub Issues: `https://github.com/Prekzursil/TanksFlashMobile/issues`
- Repository: `https://github.com/Prekzursil/TanksFlashMobile`

## What to Include in a Bug Report

- platform (`web`, `android`, `ios`, `windows`, `godot remake`, `web remake`)
- app version (from `VERSION` or release tag)
- steps to reproduce
- expected vs actual behavior
- screenshot/video if available
- exported diagnostics/logs if available

## Security Issues

Do not post sensitive security details publicly.
Open a private report through repository security contact/workflow if available.
